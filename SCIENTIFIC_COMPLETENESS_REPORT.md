## 0. The headline finding

`experiments/audit_label_leakage.py` (new, read-only) examined **all 284,807 rows** of
`GAMMA_G0_CREDITCARD_FULL_mapped.csv` and established that **5 of the 12 inputs
`gamma_test_runner.evaluate_decision()` reads are perfectly disjoint across the two classes**:

| Engine input | Value on legit (Class 0) | Value on fraud (Class 1) | Leaks label |
|---|---|---|---|
| `Gate_A3` | `True` | `False` | **YES** |
| `Gate_A7` | `True` | `False` | **YES** |
| `Lambda_G` | `True` | `False` | **YES** |
| `HARM_RISK` | varies (≈0.02) | constant `0.8` | **YES** |
| `ReasonCodes` | `CLASS_0_LEGITIMATE;…` | `CLASS_1_FRAUD;…` | **YES** |
| `Gate_A1,A2,A4,A5,A6`, `StaleContext`, `TelemetryFresh` | overlapping | overlapping | no |

Each leaking input is, alone, a **100 %-accurate classifier** on this corpus. This is not an
accusation of misconduct — it is stated openly in `gamma_map_raw.py`'s own docstring:

> `Class == 1 -> HARM_RISK high, Gate_A3 & Gate_A7 & Lambda_G fail`
> `Class == 0 -> all gates pass, Gamma = 0, PERMIT`

**Consequence.** E1's authorization accuracy and its 0-false-permit result are **conformance**
results — the reference monitor faithfully enforces the predicates it is handed. They are **not
detection** results. No claim of runtime fraud detection is supported by this corpus.

**What is unaffected.** Replay integrity (E2), formal verification (E3), predicate coverage (E9), and
non-compensatory soundness are all properties of the decision model or the evidence chain, and are
independent of how the predicates were produced.

Evidence: `label_leakage_audit.json`.

## 3. Objective C — status

**Delivered:** `experiments/experiment_runtime_detection.py` (E11).

* Blindness is **structurally enforced**, not promised: `_decide()` raises `LabelLeak` if `Class` is
  present. Verified — the guard fires.
* Calibration is unsupervised (quantiles over an unlabeled 20 % prefix).
* Labels are opened exactly once, in `_score()`, **after** every decision is hash-chained.
* Each decision emits an ERTuple (decision id, predicate vector, Γ, policy version, timestamps,
  ERTuple hash) and one append-only ledger block (prev hash, current hash, chain index).
* Self-test on a **clearly-labeled synthetic** stream: 48,000 decisions, hash chain valid, guard
  fires, non-compensatory rule confirmed (one deficit → `SAFE_STATE`).

**Blocked:** the raw ULB features (`Time`, `V1..V28`, `Amount`) are **not present anywhere in this
repository** — the mapping discarded them. `runtime_detection_report.json` was therefore written with
`status: BLOCKED` and `metrics: null`. **No numbers were invented.**

**To unblock:** place `creditcard.csv` in the repository root and run

```bash
python experiments/experiment_runtime_detection.py --raw creditcard.csv
```

This produces `runtime_detection_report.json` (Measured Runtime) with confusion matrix, false-permit
rate, false-deny rate, detection rate, Wilson 95 % intervals, Γ distribution, latency, and a verified
hash-chained ledger — cleanly separated from **Oracle Replay** (E1) and **Benchmark Conformance**
(E2/E3/E9).

**Expected outcome, stated in advance.** These are generic anomaly bounds, not domain fraud features.
Recall will be modest and the false-deny rate non-trivial. That is the honest result and it *is* the
contribution: it establishes a floor for governance-predicate authorization and separates it from the
tautological oracle result. It should be published as such, not tuned until it looks good.

## 5. Honest limitations

1. **The flagship corpus cannot support a detection claim.** §0. This is the single most important
   thing a reviewer will find, and the paper must state it before a reviewer does.
2. **No production evidence exists.** Fleet, quorum, revocation and clock-skew are a 5-node
   simulation. The repository already says so (`testbed_type: simulated-fleet`); the paper must too.
3. **`RUN_ALL_EXPERIMENTS.py` is not byte-idempotent.** Timing metrics re-measure every run;
   correctness metrics do not move. Verified by field-level diff.
4. **`predicate_coverage.json` records a transposed Wilson interval** (`low: 1.0, high: 0.772`).
   Disclosed, not silently patched — fixing it edits a published metric.
5. **E7 is blocked** on `ollama + llama3.1:8b`. Pre-existing, already disclosed.
6. **No external replication.** Single machine, single operator, no third-party audit.
