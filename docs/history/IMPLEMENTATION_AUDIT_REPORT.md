## 1. Executive Summary

The codebase is, at the level of individual functions, **largely honest deterministic code** — Wilson intervals, metric denominators, the Law-of-Concurrence aggregation, the independent replay verifier, and latency timing are genuinely computed. **However, four structural problems mean the headline results cannot be trusted as evidence of detection or verification:**

1. **TAUTOLOGY (most serious).** The credit-card "golden trace" is generated by `gamma_map_raw.py`, which sets the gate/`HARM_RISK`/`ReasonCodes`/`Status` columns **directly from the ground-truth fraud `Class` label**. The runner then "independently re-derives" the decision from those columns — i.e. it reads the label back. Every headline safety figure (100% agreement, FPR 0/492, UER 0, all six invariants hold, ConcurBench L1 "0 false permits", L2 "adaptive 0/11,808", ASB "pass 1.0") is **structurally guaranteed by construction**, not empirically earned. It demonstrates the non-compensatory logic is *wired correctly*; it does **not** demonstrate detection.

2. **TLC "verification" is attestation, not model-checking.** `verify_tlc` and `full_spec_conformance.tlc()` **do not run TLC**. The state counts (2,489,446 total / 40,192 distinct) are **constants copied from a template CSV / hardcoded** and checked only for internal consistency. Presented as "formal verification," they are paper-sourced attestations.

3. **ConcurBench Level 3 (distributed) is entirely SIMULATED.** There is no second process, node, socket, clock, or partition. "5 nodes" is the integer 5; `fleet_consistency=1.0` is the arithmetic identity `matches/matches`; and the revocation latencies (p50 8.4 / p95 16.1 / p99 20.3 ms) are **fixed-seed `random.gauss+expovariate` draws** — random-number output, not measurements.

4. **The AgentDojo "external validation" in `external_validation/` is a fabricated toy** (2 hardcoded scenarios; `false_permit_rate`/`false_denial_rate`/`latency` are literal constants) **and is wired into the live dashboard** via `run_all.py`. It is the rejected synthetic harness surfacing fake numbers as "independent validation."

**Genuinely trustworthy:** the L4 independent replay verifier (real subprocess re-verifying the 201 MB manifest end-to-end), the measured software latency (honestly disclaimed as non-hardware), the metric formulas/denominators, and — separately — the **new `agentdojo_integration/` (Phase 3A) work, which produces NO metrics/reports at all** (decision-only) and fabricates nothing.

**Success-criterion answer (up front): NO.** Not every value traces to genuine runtime computation or formally derived evidence. The exceptions are enumerated in §10–§11.

**Scope note:** this audit covers the whole repository. My own Phase 3A AgentDojo interception is included and is clean (§8.4); the problems above are pre-existing in the Gamma/LAB/ConcurBench/stress artifacts and the rejected `external_validation/` harness.
