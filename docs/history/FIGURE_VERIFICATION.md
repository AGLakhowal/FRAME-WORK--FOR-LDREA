## Checks performed
- **No fabricated points:** each SVG data point equals a CSV row equals a statistics.json entry.
  `verify_provenance.py` directly compares Fig 1 CSV counts to `statistics.json.gamma_global.distribution.counts` → **equal**.
- **No missing points:** figure category count == statistics category count (bars/cells = keys).
- **No manual editing:** SVGs are produced by string-templating functions (`_bar_chart`, `_heatmap`,
  `_write_svg`); there is no post-hoc edit step. Re-running `dashboard.generate(stats, …)` regenerates
  byte-equivalent SVGs from the same statistics.
- **Format:** SVG (scalable vector master) + CSV source. PNG/PDF derivable from SVG via any converter;
  none are hand-produced.
