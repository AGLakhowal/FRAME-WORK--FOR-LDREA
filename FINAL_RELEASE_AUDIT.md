## 1 · Everything fixed

### Critical — the failure mode that would have undermined the artifact

**Generator failures were silent.** `RUN_ALL_EXPERIMENTS.py` invoked every generator with
`subprocess.run(...)` and never inspected the return code. A crashed generator therefore left the
README, dashboard and publication package quietly disagreeing with the executed evidence, while the
harness reported a clean run.

This was **not hypothetical — it had already happened.** `experiments/generate_readme_results.py`
sorted experiment ids with `int(x[1:])`, which raises `ValueError` on the `E5b` id. The generator had
been dying on every run; the failure was swallowed; the README's auto-generated blocks had stopped
tracking the artifacts. That is why the badges read **12/12 experiments and 16/16 claims** while the
artifacts held **13 and 17**.

Fixed:

| File | Fix |
|---|---|
| `RUN_ALL_EXPERIMENTS.py` | Every generator and validator return code is now checked. Failures print loudly, the remaining generators still run, all failures are summarised at the end of the run, and generator health is persisted to `run_index.json` (`generators_ok`, `generator_failures`). |
| `experiments/generate_readme_results.py` | Ids are sorted numerically, then by suffix — a non-numeric suffix (`E5b`) can no longer crash the generator. |

**Verified in the live run:** the campaign now ends by reporting
`!! VALIDATOR REPORTED FAILURES: scientific_consistency.py (exit 1)` — a real finding that was
previously invisible. The mechanism works.

## 7 · Recommendation

> ## ⚠️ NOT READY — one blocker
>
> The repository is **technically ready**: reproducible, synchronized, fully linked, fully documented,
> tests green, benchmarks bit-identical to the frozen paper. It is **not ready to be made public** for
> one reason:
>
> **The license is not declared.** Without it, all rights are reserved by default, and an IEEE artifact
> evaluator has no explicit permission to run, copy or redistribute the code they are being asked to
> evaluate. For an artifact whose entire purpose is independent verification, that is a contradiction.
>
> ### To reach **READY FOR PUBLIC GITHUB RELEASE**
>
> 1. **Declare a license** (MIT or Apache-2.0 are the conventional choices) — replace `LICENSE`, update
>    the badge and `CITATION.cff`. *Blocker.*
> 2. **Fill the citation placeholders** in `CITATION.cff` and README §21 — or leave them as explicit
>    TODOs, but do not invent them. *Strongly recommended.*
> 3. **Reconcile the four stale prose counts** (§1 and one table row) to 13 / 17 / 12. *One word from
>    you and I will apply it — I left them because they are hand-written text.*
>
> Items 1–3 are administrative and can be done in minutes. **No scientific work remains.**
